# 07_Case_Studies

## Purpose

Enforcement narratives and lessons. Case Studies capture real (or carefully anonymized/composite) enforcement actions, settlements, and operational failures so that patterns become institutional knowledge rather than tribal memory.

## Contents

## Contribution Expectations

- Factual, source-backed where possible; clearly labeled composites when used
- Extract transferable lessons rather than pure narrative
- Link to the specific regulatory nodes that were violated or tested
