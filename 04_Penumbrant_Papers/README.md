# 04_Penumbrant_Papers

## Purpose

Gray-zone risk analysis. Penumbrant Papers map the seven (or jurisdiction-specific) penumbral risk zones where rules are unclear, contested, or untested — the places operators most often fail and where enforcement discretion is highest.

## Contents

- Explicit linkage back to the authority nodes that create the penumbra
